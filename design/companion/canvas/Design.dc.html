Screens

Header (always shown)

  • Build name and class, Loadout picker with ‹ › and Auto (match loadout to act)
  • Stats strip: DPS, Life, ES, Mana, resistances (from PoB's engine; "—" in the demo)
  • Tabs: Route, Gear, Tree, Notes with hotkey hints

Route

  • Three columns: the act's steps, gem links (PoB socket groups), the tree
  • Click a step to mark it done; shift-click marks every step before it
  • Tree shows new nodes (cyan), kept (gold), removed (dashed red), plus new notables

Gear

  • Inventory: 8 × 6 grid like the game (weapons, helmet, body, rings, amulet, gloves, boots, belt), flasks 1–5 in their slots
  • Click any item: details panel with art, base, sockets, implicits, mods and Trade
  • Right column: Jewels (tree and abyss sockets), Grafts, Guardian (Animate Guardian set, Off when the gem is disabled)
  • Main / Swap toggle only when the loadout has swap weapons
  • League picker for trade searches; Stats panel beside it

Tree

  • Large tree with the new notables and removed nodes listed

Notes

  • The PoB notes, two columns

In-game buttons

  • Small strip over the game: grip to move, Route / Gear / Tree / Notes, status dot
  • Clicking a button switches the companion screen on the other monitor
  • Window flags: top-most, no-activate (never takes focus from the game), click-through except the buttons
  • Sends nothing to the game: no key presses, no memory reads. Needs Windowed Fullscreen
  • Hotkeys Alt+1–4 do the same; automatic switching (by zone or event) later

Reading the PoB file

  • Loadouts link a tree spec, skill set, item set and config set by a tag in their titles, e.g. {a1} or {a1,a2,a3}
  • Colour codes ^2 and ^xRRGGBB are stripped from titles and labels
  • Roll ranges like (50-66)% resolve with the line's {range:x} tag (default 0.5)
  • Unique variants: keep only lines whose {variant:…} includes the selected variant
  • Header lines (Quality, LevelReq, *BasePercentile…) and flags (Corrupted, influence) are not mods
  • Implicits: the first N mod lines after Implicits: N; shown, but not used in trade searches
  • Jewels: tree sockets on allocated nodes, plus <slot> Abyssal Socket N; one card per item
  • Animate Guardian: the gem's skillMinionItemSet names the item set it wears
  • <Skill … /> can be self-closing (divider rows); parse it as an empty group
  • Auto loadout: act 1 → Act 1 set, 2 → Act 2, 3 → Act 3, 4–6 → Acts 4-6, 7–10 → Acts 7-10 (from titles)

Trade searches

Each item opens pathofexile.com/trade/search/<league>?q=<query> in the browser.

  • Uniques: name + base. Renamed items use the known unique name they start with
  • Rares, magic: slot category (helmet, ring, wand…) or exact base, plus explicit mods
  • Values: minimum about 80% of PoB's; whole numbers under 5 stay exact
  • Reduced / less: matched to the increased / more stat with a negative maximum
  • Drawbacks (flask downsides, trigger costs): required, no value
  • Local stats: defences on armour, attack stats on weapons
  • Same text, several ids: grouped as "any one of"
  • League: list from the trade API, first entry by default

Item art

  • Images are GGG's, from web.poecdn.com. The URL carries a hash, so it can't be built from the item; a lookup table is needed
  • Source: poe.ninja item data (uniques by name and base, base types, cluster jewels)
  • poe.ninja has no flask or graft bases: one trade listing per base gives its icon
  • Two-Stone Rings: art by colour pair (Ruby = Fire, Sapphire = Cold, Topaz = Lightning)
  • Demo bundles 75 images (1.2 MB). The app should download on first use and cache

For the real build

  • Stats: run PoB's own Lua calc engine (mlua), as PoB Redux does (MIT)
  • Overlay: separate small window, Win32 no-activate + top-most
  • Route: reuse exile-leveling's routes and log watcher (zone changes move the step)
  • Trade API: respect its rate-limit headers; searches open in the browser, not the app
  • Not done in the demo: real hotkeys, overlay window, PoB stats, art caching
